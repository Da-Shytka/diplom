# LetterCheck Smart

Новая версия проекта `letter-checker` с тем же общим интерфейсом, но с более устойчивой логикой разбора документа.

## Что изменено

- Документ сначала нормализуется в последовательность блоков в реальном порядке: таблицы, ячейки, абзацы.
- Шапка, адресат, обращение, основной текст, подпись и отметка исполнителя выделяются отдельным слоем классификации.
- Проверка адресата и обращения больше не зависит только от первой строки и второй ячейки первой таблицы.
- Основной текст проверяется на нормативные ссылки, орфографию, пунктуацию и стиль.
- Добавлен режим проверки обычного вставленного текста без `.docx`.
- Предпросмотр документа разделяет шапку, обращение, текст, подпись и исполнителя.

## Покрытые задачи

### Задача 1. Адресат и обращение

Проверяется:
- согласование слова `Уважаемый` / `Уважаемая` / `Уважаемые`;
- количество адресатов в шапке и обращении;
- соответствие инициалов из шапки имени и отчеству в обращении.

### Задача 2. Основной текст

Проверяется:
- формат нормативных ссылок: дата, номер, название в кавычках;
- орфография;
- пунктуация;
- официально-деловой стиль.

Для обычного вставленного текста применяются проверки задачи 2. Проверки шапки и обращения в этом режиме пропускаются.

## Запуск

### Бэкенд

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

### Фронтенд

```bash
cd frontend
npm install
npm run dev
```

Фронтенд откроется на `http://localhost:5173`.

## API

- `GET /health` — проверка доступности сервера.
- `POST /check` — загрузка `.docx`.
- `POST /check-text` — проверка вставленного текста, тело запроса: `{ "text": "..." }`.
